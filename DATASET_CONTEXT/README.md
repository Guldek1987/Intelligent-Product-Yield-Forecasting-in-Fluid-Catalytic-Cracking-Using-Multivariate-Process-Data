# Dataset Context

This folder stores supporting materials for `FCCU_DYNAMIC_NN_DATASET.csv`.

Contents:

- `data/raw/ml_pse_fccu/` - original downloaded ML-PSE FCCU files.
- `data/interim/ml_pse_fccu/` - generated scenario files, dictionaries, recommended features, targets, and manifest.
- `docs/project_brief/` - project documents used to define the Dynamic NN task.
- `docs/sources/` - source notes and dataset references.
- `project_files/` - helper scripts, Python loading code, requirements, notebooks/models/report placeholders, and previous root README.

The main working dataset stays outside this folder:

`../FCCU_DYNAMIC_NN_DATASET.csv`

Use the context files only when checking provenance, rebuilding the dataset, or clarifying variable/scenario meanings.

Current project root is intentionally minimal:

- `FCCU_DYNAMIC_NN_DATASET.csv`
- `DATASET_CONTEXT/`
